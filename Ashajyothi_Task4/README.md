# Online Examination System

## Description
A Java-based Online Examination System that allows users to log in, answer multiple-choice questions, and receive instant results.

## Features
- User Login Authentication
- Multiple Choice Questions
- Automatic Score Calculation
- Percentage Calculation
- Pass/Fail Status
- Exam Time Tracking
- Logout Functionality

## Technologies Used
- Java
- VS Code

## How to Run

1. Compile the program:
   javac OnlineExam.java

2. Run the program:
   java OnlineExam
