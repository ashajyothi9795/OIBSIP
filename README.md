# ATM Interface Project

This is a simple Java-based ATM Interface project created for internship submission.

## Features
- User login with PIN
- Balance checking
- Deposit money
- Withdraw money
- Transaction handling

## Technologies Used
- Java
- OOP Concepts

## Files
- ATMInterface.java
- BankAccount.java

## How to Run
1. Compile the Java files
2. Run the ATMInterface class
